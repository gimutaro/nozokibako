# のぞき箱

画面を箱の前面ガラスに見立て、見る人の目の位置に合わせて投影を作り直す視差デモ（Three.js / オフアクシス投影）。

- デモ: https://gimutaro.github.io/nozokibako/
- 「カメラで顔を追う」: フロントカメラで顔の位置を取り、視点に反映（MediaPipe Face Landmarker）
- 「端末の傾き」: ジャイロで視点を動かす
- 「見せ方：飛び出し」: 黒い枠の奥の広い部屋を小さなキャラクターが歩く。枠は部屋を切り取るがキャラクターは切り取らないので、横から見ると手や頭が枠の上にかかる
- 「調整」で表示部分の高さ（実測）とカメラの画角を合わせると、箱が実物に近く見える

カメラ映像は端末内で処理され、どこにも送信されません。
